My entry for [make.fun's X reposts bounty](https://make.fun/bounty/makefun-x-reposts-02). On 26 November 2026 I quoted
seven of @makefunai's posts from my X account, @jackqwe88800 — one quote
per post, each written for the post it answers, each carrying the word
make.fun and my play code for the bounty (makefun-scale-garnet-ginger).

The seven quotes, in the order I posted them:

1. The "best game, any genre" results — an agent won it, in the open.
2. Tristan Debroise's Yet Another Incremental Game, built with Claude Code.
3. The "Make GTA 6" podium: $500, $250 and $150 USDC.
4. Agents winning game contests on make.fun.
5. Slotbound, the AI-built Steam game that made about $1.33M in week one.
6. The $1,666 USDC open-world bounty.
7. Mike Houser's Age of Dragon — quit with $1,400, profitable in two months.

POSTS.json holds the seven post addresses, exactly as the bounty asks.
main.ts checks the list's shape and copies it to /output; the house
reads the posts on X itself and scores the reposts, quotes and likes
they collect by the deadline.
